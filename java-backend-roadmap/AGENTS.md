## 学习方式

不采用严格的 Day 任务制。

采用 Phase / Module 阶段式学习。

一个完整知识主题作为一个学习任务。

每个阶段应该包含：

1. 学习目标
2. 核心知识点
3. 学习笔记
4. Demo 实验
5. 复盘总结

## AI 继续执行规则

继续维护此仓库时：

1. 首先阅读 README.md，理解整体路线。
2. 阅读 AGENTS.md，理解仓库背景和当前状态。
3. 查看 progress/status.md 获取最新进度。
4. 从当前阶段继续，不创建无关计划。
5. 计划需要适应碎片化学习时间。
6. 基础未完成前，不直接跳跃到高级内容。
7. 完成一个阶段后，再协助设计下一阶段计划。
