# Phase 7 - 项目复盘与面试准备

## 目标

把 Netty / RPC 项目和 Agent 项目整理成面试能讲的内容，完成简历优化、高频题练习和模拟面试。

## 内容

### 项目复盘

- 选择 Server 项目 1 个（Netty / RPC / 网关）
- 选择 Agent 项目 1 个（LLM / RAG / Tool Calling）
- 梳理：业务背景、技术架构、核心流程、难点、优化
- 每个项目准备 10 分钟讲解稿

### 面试准备

- Netty：线程模型、ByteBuf、粘包拆包、心跳
- 网络与 OS：TCP、IO 多路复用、零拷贝
- Java：集合、并发、JVM
- 数据库与缓存：MySQL、Redis（工作基础）
- 场景题：高并发、连接池、超时、重试、分布式
- Agent 基础：RAG、Tool Calling、Agent 框架

### 简历

- 突出 Netty / 服务器项目
- 体现 Agent 项目作为加分项
- 量化项目产出
- 强调独立开发能力

## 完成标准

- Server 项目能 10 分钟讲完
- Agent 项目能讲清基本流程
- 能回答 5 个以上项目追问
- 简历完成并找他人 review
- 完成至少 3 次模拟面试

## 学习建议

- 不要最后才开始整理项目，Phase 4 开始就要边做边记录
- 八股题按“能讲原理 + 能举例子”准备，不要死背
