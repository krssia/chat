# Phase 5 - RPC 与高性能服务扩展

## 目标

在 Netty 基础上继续深入服务器开发，把 Phase 4 项目扩展成 RPC / 网关 / 高性能服务，增加跳槽竞争力。

## 内容

### RPC 核心

- 序列化协议：JSON / Protobuf / Hessian
- 自定义协议设计
- 服务注册与发现
- 负载均衡
- 超时、重试、熔断
- 线程模型与连接管理

### 高性能服务

- 连接池与并发参数调优
- 背压与流量控制
- 性能测试与压测
- 常见问题：连接风暴、内存泄漏、CPU 高

## 完成标准

- 能讲清一个 RPC 调用从客户端到服务端的完整流程
- 能设计一个简单自定义协议
- 能把 Phase 4 项目扩展成 RPC 或网关项目
- 能说明项目中如何做超时、重试、负载均衡
- 能给出至少一个性能优化点

## 学习建议

- 不要自己重复造完整 RPC 框架，重点是理解核心链路
- 可以先参考 Dubbo / gRPC 的设计，再用 Netty 实现最小版本
- 项目要能压测并记录数据
