# Phase 6 - Agent 开发基础

## 目标

作为副线，掌握 Agent 开发的核心链路，能够做出一个 Java Agent Demo，作为跳槽时的加分方向。

## 内容

### LLM 基础

- 大模型基本概念
- 模型 API 调用
- Prompt 设计

### RAG

- 文档加载与拆分
- 向量化 Embedding
- 向量数据库检索
- 生成增强

### Agent

- Tool Calling
- Function Calling
- Agent 循环：规划 → 调用工具 → 观察 → 继续
- Agent Framework：LangChain4j / Spring AI 等

## 完成标准

- 能调用一个 LLM API 并完成简单对话
- 能实现一个 RAG Demo
- 能实现一个带 Tool Calling 的 Agent Demo
- 能解释 Agent 的基本循环流程
- 能讲清 RAG 解决什么问题

## 学习建议

- 作为副线，不需要追求过深，先做出可演示 Demo
- 优先用 Java 技术栈，方便和你现有经验衔接
- 项目可以和工作中业务结合：文档问答、智能客服、代码助手
