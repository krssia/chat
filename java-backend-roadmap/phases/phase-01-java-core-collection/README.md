# Phase 1 - Java 基础与集合

## 学习定位

本阶段学习 Java Collection Framework。

目标不是简单记忆 API 或源码，而是建立后端开发中正确使用集合的能力。

通过：

理论学习 → Demo 实验 → 问题分析 → 总结复盘

逐步理解集合设计思想。

---

## 学习目标

完成本阶段后，应能够：

- 根据业务场景选择合适集合
- 理解 List、Set、Map 的核心结构
- 理解常见集合实现原理
- 分析 equals/hashCode 对集合的影响
- 解释 HashMap 等集合的关键机制
- 通过代码 Demo 验证理解

---

## 知识范围

## 1. List

学习：

- ArrayList
- LinkedList

重点：

- 数组结构
- 链表结构
- 查询与插入性能差异
- 扩容机制

---

## 2. Set

学习：

- HashSet
- TreeSet

重点：

- 唯一性保证
- 哈希存储
- 排序集合

---

## 3. Map

学习：

- HashMap
- LinkedHashMap
- TreeMap

重点：

- Key-Value 结构
- 哈希定位
- 冲突处理
- 扩容机制
- 有序 Map

---

## 4. 通用基础

包括：

- equals/hashCode
- hash 算法
- 集合选择原则
- 常见使用场景
- 性能分析

---

## 学习流程

每个知识点按照以下流程：

1. 理解概念
2. 阅读实现原理
3. 编写 Demo
4. 修改代码验证
5. 总结问题
