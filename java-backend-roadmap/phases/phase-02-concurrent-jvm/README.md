# Phase 2 - 并发与 JVM

## 目标

掌握 Java 并发基础和 JVM 核心知识，能够解释工作中遇到的并发问题、线程池使用和内存排查问题。

## 内容

### 并发

- Thread
- Runnable
- Callable
- synchronized
- volatile
- Lock
- ThreadPool

### JVM

- JVM 内存区域
- 类加载机制
- GC 与常见垃圾回收器
- JVM 参数
- OOM / CPU 高问题排查思路

## 完成标准

- 能解释线程池核心参数和拒绝策略
- 能说出 synchronized / volatile / Lock 的区别
- 能描述 JVM 内存结构和 GC 流程
- 能给出 OOM / 高 CPU 问题的排查思路
- 完成并发 Demo 和 JVM 笔记

## 学习建议

- 结合工作中实际遇到过的线程池、超时、内存问题学习
- 每个知识点先自己讲一遍，再让 AI 检查是否准确
