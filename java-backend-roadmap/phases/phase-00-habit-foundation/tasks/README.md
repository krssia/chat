# Task: Phase 0 - 习惯与现状盘点

## 学习目标

用最快速度完成正式学习前的准备：盘点工作现状、确认薄弱点、建立最低学习习惯，然后进入 Phase 1。

## 学习资源

- JavaGuide 主页（资料索引）：https://javaguide.cn/
- 怎么用：本任务主要是盘点现状，不需要大量学习资料；遇到不确定的技术名词，用 JavaGuide 搜索对应词条即可，不用深入
- 重点看：不需要，本任务重点是盘点，不是学习新知识

## 需要掌握 / 需要输出

- 当前工作技术栈：框架、数据库、中间件、任务类型
- 日常负责的任务类型：CRUD、接口、定时任务、脚本等
- 每天 / 每周大概可投入的学习时间
- 离开 AI 后不敢动手的知识点
- 主攻方向：Server 开发主线 + Agent 开发副线
- 跳槽节点：学完 Netty + 完成 Netty 项目后开始投递

## 推荐学习顺序

1. 盘点工作现状（技术栈 / 任务 / 时间）
2. 列出薄弱点
3. 制定每日最低学习习惯
4. 更新 progress/status.md
5. 正式进入 Phase 1

## 实践内容

- 填写“工作技术清单”
- 列出至少 5 个薄弱点
- 制定个人最低学习习惯：加班日 15～30 分钟也算
- 在 2～3 天内完成 Phase 0，不要拖延

## 思考问题

- 我现在离开 AI 能独立完成哪些任务？
- 当前最影响我工作产出的短板是什么？
- 为了 Netty / Server 开发，我最需要补哪些前置知识？
- 我每天最低能保证多少学习时间？
- Agent 副线什么时候开始接触比较合适？

## 完成标准

- 已输出工作技术清单
- 已列出 5 个以上薄弱点
- 已确认跳槽方向和节点
- progress/status.md 已更新
- 可以正式进入 Phase 1：Java 核心与集合
