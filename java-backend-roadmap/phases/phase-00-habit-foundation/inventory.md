## 薄弱点清单

- Java 基础与集合：能写 CRUD，但底层原理和集合机制不系统
- 并发 / JVM：线程、锁、线程池、GC 基本没系统学
- 网络 / IO / Netty：TCP、NIO、IO 多路复用、Netty 需要从零开始
- 独立开发能力：离开 AI 后不敢动手，缺少独立设计模块和排查问题能力
- Spring / 数据库 / Redis：工作在用，但只能说出“怎么用”，讲不清原理
