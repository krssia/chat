# Phase 0 - 习惯与现状盘点

## 目标

- 建立“每天多少学一点”的最低学习习惯
- 盘点工作技术栈和个人薄弱点
- 明确 6 个月跳槽目标

## 背景

当前学习时间不稳定，可能加班、可能很晚回家，所以这一阶段不追求学习量，只追求“不断掉”。

## 需要完成

1. 每天下班至少 15～30 分钟学习或复习
2. 记录本周工作用到的技术：框架、数据库、中间件、接口类型
3. 列出“离开 AI 后不敢动手”的知识点
4. 确认 6 个月目标：独立开发 + 面试准备
5. 输出个人技术清单和薄弱点清单

## 推荐做法

- 工作日：复习旧知识 / 读一篇文档 / 看一段工作代码
- 加班日：只做 15 分钟复习即可
- 周末：做一次本周总结，更新 progress/status.md

## 完成标准

- 连续 2 周保持最低学习习惯
- 能列出当前工作技术栈
- 能列出 5 个以上需要补的薄弱点
