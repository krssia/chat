# Phase 0 - 习惯与现状盘点

## 目标

快速完成跳槽路线的前置准备：盘点现状、确认薄弱点、建立最低学习习惯，然后正式进入 Phase 1。

## 背景

当前学习时间不稳定，可能加班、可能很晚回家，所以 Phase 0 不追求学习量，只追求“快速盘点 + 不断掉”。

## 需要完成

1. 盘点工作技术栈：框架、数据库、中间件、任务类型
2. 列出“离开 AI 后不敢动手”的知识点
3. 确认主攻方向：Server 开发为主线，Agent 开发为副线
4. 确认跳槽节点：学完 Netty 并完成 Netty 项目后开始投递
5. 输出个人技术清单和薄弱点清单
6. 制定每日最低学习习惯：加班日 15～30 分钟也算

## 推荐做法

- Phase 0 控制在 2～3 天内完成，不要拖
- 工作日：利用下班时间盘点现状
- 加班日：只做 15 分钟复习即可
- 完成盘点后立即进入 Phase 1，最低学习习惯在 Phase 1 中持续保持

## 完成标准

- 已输出工作技术清单
- 已列出 5 个以上薄弱点
- 已确认跳槽方向和节点
- progress/status.md 已更新
- 进入 Phase 1 时，每天仍保持“至少学一点”的习惯
