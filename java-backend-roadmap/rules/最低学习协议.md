# 最低学习协议

> 目标：建立一个可以长期坚持半年到一年的学习节奏，而不是短期爆肝。

---

# 核心原则

不要追求每天学习很多。

目标是：

```
稳定积累 × 长期坚持
```

而不是：

```
短期爆肝 × 快速放弃
```

---

# 工作日学习标准

## 最低标准

每天：

```
30分钟
```

即使非常累，也完成最低学习量。

可以是：

- 看昨天笔记
- 阅读一个知识点
- 修改一个 Demo
- 整理一个问题

---

## 正常标准

每天：

```
60~90分钟
```

推荐安排：

```
20:00 - 21:30

学习 / Demo / 项目
```

---

## 上限标准

每天：

```
2小时
```

不要为了学习牺牲长期睡眠。

---

# 周末学习标准

## 最低标准

每天：

```
2小时
```

保持学习连续性。

---

## 推荐标准

每天：

```
4小时左右
```

安排：

- 上午学习新知识
- 下午写 Demo 或项目
- 晚上娱乐休息

---

# 游戏与娱乐规则

游戏不禁止。

游戏是恢复精力的一部分。

建议：

工作日：

```
完成最低学习目标后娱乐
```

周末：

```
安排固定游戏时间
```

不要因为娱乐产生负罪感。

---

# 疲劳日处理方式

如果当天：

- 加班
- 身体疲惫
- 精神状态差

不要强迫自己完成大量内容。

只完成：

```
15~30分钟复习
```

即可。

重点：

不要出现连续多天完全停止学习。

---

# 学习延期规则

不要因为没有完成计划而放弃。

例如：

计划：

```
7天完成HashMap
```

实际：

```
10天完成
```

完全接受。

目标是掌握知识，而不是完成日历。
