# Java Backend Roadmap v2

> 目标：作为已经进入开发岗位的 Java 后端新人，系统补齐基础能力，提高独立开发和解决问题的能力，为未来跳槽准备。

## 学习定位

当前阶段：

- 已经接触真实开发工作
- 需要提升 Java 基础和工程能力
- 降低对 AI 生成代码的依赖
- 建立独立分析、设计和实现能力

长期方向：

- Java Backend
- Server Development（Netty / RPC / 高性能服务）
- AI Agent Development（LLM / RAG / Agent）

## 学习原则

不追求快速刷完知识点，而是建立长期积累：

理论 → Demo → 独立修改 → 总结 → 应用

不采用 Day 任务制，按照完整模块推进。

## 当前阶段规划

### Phase 01：Java Collection

目标：理解 Java 常用集合设计和使用方式。

包含：

- ArrayList
- LinkedList
- HashMap
- HashSet
- 常见集合问题

### Phase 02：Java Concurrent

目标：掌握 Java 并发基础，为后续高性能开发打基础。

包含：

- Thread
- synchronized
- volatile
- Lock
- ThreadPool

### Phase 03：Spring Basic

目标：理解 Java 后端框架核心机制。

包含：

- IOC
- Bean 生命周期
- AOP
- 事务
- Spring MVC 基础流程

## 后续方向

### Server Development

- 计算机网络
- TCP/HTTP
- Netty
- WebSocket
- RPC
- 高性能服务器

### AI Agent

- LLM 基础
- 模型调用
- RAG

## 学习方式

每个模块：

1. 理解核心概念
2. 编写最小 Demo
3. 修改需求进行练习
4. 总结 Markdown 笔记
5. 阶段复盘

## 记录原则

- 不绑定当前工作项目
- 不依赖旧项目
- 不按天强制推进
- 保持碎片时间也能持续推进
