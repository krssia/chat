# Java 后端工程师成长路线

> 目标：普通本科应届 Java 后端开发，通过 6 个月快速提升，准备跳槽；1 年内形成 Java + 高性能 + AI 的技术竞争力。

## 路线

### 0-6个月：快速跳槽阶段

重点：

- Java 基础
- JUC 并发
- JVM
- MySQL
- Redis
- Spring Boot
- MQ
- Linux
- Docker
- 项目能力

### 6-12个月：持续成长阶段

重点：

- Netty
- 网络编程
- RPC
- Spring 源码
- 云原生
- AI Agent

## 项目路线

1. 企业权限管理系统
2. Netty IM 即时通讯系统
3. AI Agent 平台

## 学习方式

每个知识点遵循：

理论 → Demo → 修改 → 独立实现 → 项目应用 → Code Review

持续记录学习笔记和代码。
