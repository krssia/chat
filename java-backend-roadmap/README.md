# Java Backend Roadmap v2

> 目标：作为已经进入开发岗位的 Java 后端新人，系统补齐基础能力，提高独立开发和解决问题的能力，为未来跳槽做准备。

## 学习原则

不追求快速刷完知识点，而是建立长期积累：

理论 → Demo → 独立修改 → 总结 → 应用

## 阶段规划

### Phase 1：Java 核心能力

- Java 集合
- 面向对象
- 泛型
- 异常
- IO
- 常用工具类

### Phase 2：Java 工程基础

- 多线程
- JVM基础
- Maven
- Git
- Linux基础

### Phase 3：后端核心技术

- MySQL
- Redis
- Spring
- MyBatis
- 消息队列

### Phase 4：提升阶段

- 源码阅读
- 性能优化
- 系统设计
- 网络编程

## 学习方式

每个模块：

1. 理解核心概念
2. 编写最小 Demo
3. 修改需求进行练习
4. 总结 Markdown 笔记
5. 定期复盘

## 记录原则

- 不按天强制推进，按模块完成
- 保持碎片时间也能持续推进
- 重视理解，不追求堆积代码
