## AI 使用方式

目标：
从“看懂 AI 写的代码”提升到“自己设计并完成功能，AI 辅助优化”。

推荐流程：
1. 自己分析需求。
2. 自己设计类和流程。
3. 自己实现核心代码。
4. 遇到问题再询问 AI。
5. 使用 AI 做 Review、测试和方案比较。

避免：
- 直接生成完整项目后复制。
- 不理解代码就提交。
